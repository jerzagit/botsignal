### 1.2 Primary production flow (Telegram signal)

```
Telegram channel message
        ↓
core/listener.py :: on_new_message
        ↓
parse_close_alert  OR  parse_with_profile(...)
        ↓
core/state.py pending[signal_id] + core/db.py upsert_signal("pending")
        ↓
auto_execute?
   ├─ false → dry-run Telegram notify only
   └─ true
        ↓
LAYER_MODE?
   ├─ true  → core/layer_watcher.py :: watch_layered_entry
   └─ false → core/watcher.py :: watch_and_execute
        ↓
price enters zone / layer trigger (live tick poll every WATCH_INTERVAL_SECS)
        ↓
core/mt5.py :: execute_trade(...)   ← ALL major guards live here
        ↓
MetaTrader5.order_send (magic 20250101)
        ↓
DB record_trade + data/trades.json
        ↓
Telegram result → YOUR_CHAT_ID
```

### 1.4 Secondary auto-entry paths

1. **AutoZone** — manual `/snr` + `/map` → `map_watcher` → `execute_trade` (`entry_mode=mapped`)
2. **Strategy** — M15 breakout-retest → `execute_trade` (`entry_mode=strategy`, `skip_proximity=True`)
3. **Manual gold** — `/goldbuynow|/goldsellnow` → `execute_trade` (`entry_mode=manual`, skips proximity/RR/session)
4. **Fib alert button** — scanner alert → user taps BUY/SELL NOW → manual pipeline

### 1.5 Critical finding: agent signal path unwired

`agent/agent.py :: agent_handle_signal` can execute / confirm, but **listener never calls it**.  
`start_agent()` only announces + hourly heartbeats when agent hours are active.

| guard_id | name | condition | recorded via `_fire_guard`? | skip flag |

**Soft adjustments (not hard blocks):** tight-SL auto TP (`SL_MIN_PIPS` / `TP_ENFORCE_PIPS`); stack mode `reduce` (lot cut).

### 3.2 Lot sizing — `core/risk.py :: calculate_lot`

Zero lot if: no account, no free margin/equity, no symbol, zero tick, zero SL distance, insufficient margin for `MIN_LOT`.

### 3.3 Strategy pre-guards — `core/strategy.py :: scan_once`

Live locked; session; connect; strategy daily DD vs equity %; existing open position on symbol; spread; insufficient candles; `_trend_allows` fail; RR vs `STRATEGY_MIN_RR`.  
Skips often `record_guard_event("strategy", ...)`.

### 3.4 Layer watcher extras — `core/layer_watcher.py`

SL distance caps layers; external cancel if signal removed from `pending`; soft/hard expiry; L2 trigger beyond SL; **runway** `L2_MIN_RUNWAY_PIPS`; spread/market closed retry; unknown ticket → stop; L1 stack retry; L1 other guards fatal; L2+ skip layer.

### 3.5 Soft-only (do not hard-block `/gold*`)

`check_trend_alignment`, `check_fib_entry` — warn UI; **fail-open** if candle data missing.

## 7. IDENTIFIED GAPS (ranked)

### CRITICAL

1. No historical replay loop; execution assumes live MT5 account + ticks.  
2. Lot/risk depends on live free margin — not reproducible from OHLC alone.  
3. Daily loss breaker is **process memory**, mainly updated by **dashboard poller** — bot-alone hist sim would mis-model it.  
4. Agent auto-exec path documented ≠ wired.

### HIGH

5. Wall-clock `SIGNAL_EXPIRY` + session filter — need ReplayClock injection.  
6. Watchers poll live price — need bar/tick replay model.  
7. Fib/trend **fail-open** without MT5 — silent guard bypass in broken feeds.  
8. Layer/stack/source risk need simulated open-position book.  
9. Dual profit-lock (watcher vs poller) — pick one semantics for sim.

### MEDIUM

10. AutoZone zones are **manual**, not detected SND — 12-month AutoZone replay needs zone generation policy.  
11. “Fib” is last opposite H1 candle 0–38.2%, not classic swing Fib lifecycle.  
12. Dead config: `SOURCE_CONFLICT_MODE`, `STRATEGY_PARTIAL_CLOSE_*`.  
13. Intrabar SL+TP ambiguity undefined.

### LOW

14. Telegram UI / Telethon not needed for pure strategy replay.  
15. Startup AutoTrading / account-switch env coupling.

## Appendix A — Timeframe / candle usage (production)

| Component | Timeframe | Forming vs closed |
|-----------|-----------|-------------------|
| Strategy breakout | M15 | Uses `candles[:-1]` closed; last bar treated carefully in `evaluate_breakout_retest` |
| Trend / Fib | H1 (Fib), H1+H4 (trend) | `copy_rates_from_pos` — typically includes current forming bar; Fib uses completed opposite candle logic inside `check_fib_entry` |
| Signal watcher | Tick | Live bid/ask, not closed H1 |
| Session filter | Wall UTC hour | Not bar-based |

**Inconsistency to document in replay:** signal entries are **tick/proximity** driven; strategy is **closed M15** driven. Replay must not mix these models silently.

## Appendix B — Look-ahead policy (required later)

For any future swing-with-right-confirmation:

- If `SWING_RIGHT = N`, pivot becomes visible only after N bars exist **at or before ReplayClock.cursor**.  
- Strategy today does **not** use left/right swing pivots for Fib anchors — do not add look-ahead by inventing that feature in the backtester.

## Appendix C — Suggested run id format

```
BT_XAUUSD_<FROM>_<TO>_<NNN>
```

Store `meta.json`: symbol, broker/server (no secrets), date range, git commit, branch, config snapshot hash, data source, started/completed.

## Appendix D — Intrabar ambiguity policy (draft)

When a simulated bar’s range touches both SL and TP:

1. Mark event `AMBIGUOUS_INTRABAR`  
2. Do **not** silently pick the profitable outcome  
3. Future resolution options: M1/M5 replay, tick replay, or conservative (SL first) — choose explicitly in run meta
